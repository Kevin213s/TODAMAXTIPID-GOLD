Full Data Backup (Discord Database)

Everything is saved in this browser automatically. Use these buttons to also keep a full off-device copy in your Discord channel: all transactions and sales analytics, product inventory & stock, cashier staff, Perks members and shift logs (one .json file plus .csv sheets). Passwords and Discord secrets are never included.

Needs the Bot Token. When both are saved, backups are posted by the bot so it can read them back later (the bot also needs Read Message History there). Backups posted earlier by a webhook can only be read if the bot has Message Content Intent turned on in the Developer Portal.

Restore only adds what is missing (new invoices, products by barcode, staff and members by ID); existing records are left untouched. Restored staff get the temporary password cashier123.

Discord Database (SQL-style tables)

Each record is stored as one message (a "row") in a private Discord channel, tagged with its table: products, staff, members, transactions, sessions. Rows are updated in place (upsert), and you can read them back with SQL SELECT queries. Requires the Bot Token above (webhooks cannot read data back), and the bot needs View Channel, Send Messages, Read Message History in that channel.

Channel per table (right-click a channel → Copy Channel ID)
